# 适用边界与触发说明

本文件帮助 Agent 判断：当前请求是否应启动 `arbitration-hearing-prep`。

## 一、本技能做什么

产出**给人读的**庭前文书：争议焦点分析、法律依据与参考案例、分层庭审问题清单（Word + HTML）。

## 二、何时启动

用户交付案件材料，并出现以下需求之一：

- 庭审问题清单、庭前问题清单、庭审提纲、发问清单
- 出庭材料、争议焦点与法律依据、争议焦点分析报告
- 「按庭审准备体系做」「直接出 Word」等明确指令
- 需要把庭前材料规范命名后整理归档

## 三、何时不要启动

用户要求起草、改写或签发前核对**终版裁决书/判决书主文**时，不要用本技能（那是另一类文书工作，不在本仓库范围）。

仅出现中性词「争议焦点」「提问清单」时：确认用户要的是庭前 Word/HTML 交付件；若其实是要写终版裁决/判决主文，转去对应技能或先问一句。

## 四、与系列其他技能

本技能是「arbitration」方法论系列的庭审准备篇。若同时安装了同系列的裁决书起草技能，按交付物区分：

| 需求 | 技能 |
| --- | --- |
| 庭审问题清单 / 争点与法条分析 / Word 庭前材料 | `arbitration-hearing-prep`（本技能） |
| 程序稿 → 终版裁决书、补仲裁庭意见、签发前检查 | 裁决书起草类技能（若已安装） |

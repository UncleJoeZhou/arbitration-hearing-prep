# 正式文书风格铁律

庭审材料是给裁判者看的正式严肃文书，风格必须"死板、规范、零花哨"。

## 1. 字体与颜色

- **字体：通篇宋体。** 标题不另用黑体，靠字号与加粗区分层级。
- **颜色：通篇黑色。** 不用藏青标题、酒红强调、灰色注释等任何彩色。
- 实现技巧（python-docx）：把颜色常量统一设为 `RGBColor(0,0,0)`、字体常量统一设为宋体，一处改、全文档生效。

## 2. 文风

- 公文化、自然段化、短句。
- 去 AI 堆砌感：少用悬浮的 bullet 清单，多用自然段；保留必要的结构化标题分级。
- 一句话能说完的不要拆成三条要点。

## 3. 禁用跳脱话术（口语/营销腔）

以下词汇一律禁止出现在正式文书，须改公文化表述：

| 禁用 | 改为 |
|---|---|
| 类案精析 | 参考案例 |
| 庭审使用 | 适用于本案的结论与建议 |
| 最强类案 / 与本案最相似 | 重要参考案例 / 与本案案情相近 |
| 主攻方向 | 核心争点 |
| 反制点 | 抗辩理由 |
| 实质证明 | 充分证明 / 证明 |
| 击破 / 击穿 / 直接翻转 | 客观中性表述 |
| 兜底 / 拿捏 / 防火墙 | 客观中性表述 |

- 删除【核心】【关键】【举证责任】等彩色标记性标签与 emoji（如 ⚖）。

## 4. 参考案例结构化引述

每个参考案例固定三段：
1. **案例内容**（案情概要）；
2. **裁判规则**；
3. **适用于本案的结论与建议**。

## 5. 禁失效 markdown 标记

- 数据里若用 `**...**` 表加粗，渲染成 Word 会残留字面 `**` 星号——**大忌**。渲染层必须 strip 掉 `**`。

## 6. 编号与层级

- 编号从"一"开始，**不从"〇"开始**。
- 层级用规范中文编号：一、／（一）／1.／（1）。

## 7. 标点

- 中文文本一律全角标点（，。、；：“”？！（）《》等），双引号用“”。
- 例外保持半角：代码块及行内代码、文件名、路径、URL、邮箱、纯英文句子内部、数字中的小数点与千分位。
- 中文与英文、数字、半角符号之间不加空格，直接相连。

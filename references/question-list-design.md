# 庭审问题清单分层设计方法

问题清单是庭审准备的核心交付物。要"完整、干净、有层次"，不是一堆零散问题。

## 1. 分层分组（顶层结构）

按合同机制或争议逻辑分组。以本案（商品房委托代理销售合同佣金纠纷）为例的分组：

1. 合同的签订与效力（意思表示真实、格式条款知情）；
2. 欠付数额与拆分（多笔款项须拆分，逐笔审查，不可笼统）；
3. 核心争点的有效性/履行判定（本案为"是否构成有效推荐客户"）；
4. 抗辩审查（本案为"已结清／重复主张"抗辩）；
5. 违约金与利息（约定违约金的适用关系）；
6. 费用承担与调解。

## 2. 核心争点按流程递进（组内再分层）

对最关键、最复杂的争点，按其业务流程或合同约定的判定流程再细分层。本案"推荐有效性"按合同机制分六层递进：

报备 → 到访 → 判定 → 成交确认 → 无效情形 → 异议期。

每一层对应合同约定的一个环节，逐层设问，形成完整的审查链条。

## 3. 每问四要素

每个问题固定四要素，缺一不可：

- **发问对象**：问申请人 / 问被申请人 / 问双方；
- **依据条款**：对应的合同条款号或法条；
- **问题**：短句、直接、可当庭照读；
- **设问目的**：这一问要锁定什么事实、分配什么举证责任、堵住什么漏洞。

## 4. 举证责任分配

- 谁主张谁举证（《民事诉讼法》第六十七条）。
- 识别合同中的"不利后果分配"条款（如本案"网签后90日内未提出书面异议视为确认有效推荐"），把这类条款对应的设问置于高位——它往往是己方最有力的支点。
- 对对方的抗辩，设问要求对方"落到具体条款＋提交具体证据"，不接受空泛主张。

## 5. 围绕请求权基础与抗辩设问

- 我方主张：围绕请求权基础的构成要件逐一设问、逐一固定。
- 对方抗辩：围绕抗辩的构成要件设问，逼对方举证或暴露缺口。
- 不泛泛而谈，每一问都服务于一个争点的证明或反驳。

## 6. 程序性问题单独列

- 当事人身份、代理权限、是否申请回避、争议焦点归纳确认、调解意愿等程序性事项，单独归为一组，置于问题清单前部或庭审提纲中。
